# Relfor Inventory & Donation Allocation System

A web-based inventory and donation allocation management system developed for **Relfor Foundation** as a Service Learning technical project.

The system is designed to help the foundation manage donated resources, track inventory, process resource requirements from NGOs/beneficiaries, allocate available resources, record actual distributions, and maintain a complete allocation history.
